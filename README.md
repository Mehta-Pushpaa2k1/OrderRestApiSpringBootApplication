# SpringBootRestApplication

## Project Description
This project is a Spring Boot REST API application for Order Management.

## Features
- Create Order by ID and Email
- Read Order Details by ID and Email
- Update Order by ID and Email
- Delete Order by ID
- Implemented CRUD Operations
- Used OOP Concepts and Spring Boot Annotations

## Technologies Used
- Java
- Spring Boot
- REST API
- Maven
- Postman
- Database: PostgreSQL (as used in the project)

## Testing
All REST API operations are tested using Postman.
